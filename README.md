🎨 Random Color Generator
📌 About

Random Color Generator is a simple and interactive web application that generates random colors with just one click. It allows users to explore different colors and view their HEX color codes.

✨ Features
Generate random colors.
Display HEX color codes.
Change background color instantly.
Generate new colors with one click.
Simple and attractive user interface.
Responsive design.
Easy-to-use functionality.

🛠️ Technologies Used
HTML5
CSS3
JavaScript

🚀 How to Run
Clone this repository:
bash
git clone YOUR_REPOSITORY_URL

Open the project folder.
Open index.html in your web browser.
Click the Generate Color button.
Enjoy exploring random colors!
